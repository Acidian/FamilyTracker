# Nightlight design

## Approved direction
User selected concept 03 Nightlight. A tired parent checks medicine beside a child's bed in a dim room, so the interface uses a dark, low-glare navy base.

## Visual system
Full palette with defined roles: deep navy canvas, muted lavender surfaces and selections, warm peach primary actions, mint recorded states, warm coral errors. Serif page titles, sans serif controls and dose data. Circular family avatars, generous breathing room, compact bottom navigation on phones and a persistent side rail on desktop.

## Fidelity inventory
Preserve the crescent moon mark, large Today heading, family selector, prominent next-dose panel, attribution to a parent, quieter agenda rows, voice/camera shortcuts, and four navigation destinations. Build the UI as semantic HTML, CSS and icon components. Portraits become editable initials avatars so no external portrait assets are required. Decorative mockup scenery and marketing copy stay outside the working app.

## Interaction
Forms use full-page or inline panels. Dose confirmation displays medicine, strength, quantity/unit, person, scheduled time and actual time. Explicit given/skipped states; no automatic recording on notification dismissal. Empty, offline, device-only, loading, saving and failed states are visible.
